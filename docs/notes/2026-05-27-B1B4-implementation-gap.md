### 产出计算

| 指标 | 值 |
|------|-----|
| 制造站生产力 | 1.835 |
| 纯技能加成 | 80.5% |
| 期望值 | 140.0% |
| **偏离** | **-59.5 个百分点** |

### 加成明细

| 来源 | 贡献 |
|------|------|
| 酒神 戏中人 | +35% |
| 玛露西尔 差遣使魔·β | +30% |
| 迷迭香 B3 (24链环) | +12%（24h 期内积分折半为 +24/2=12%） |
| 玛露西尔 B4 (3魔物料理) | +1.5%（24h 期内积分折半为 +3/2=1.5%） |
| **合计** | **78.5%** |

> 注：synergy.py 模块常量 `T = 12.0`（12h 排班），但 production.py 以 24h 为积分区间。
> synergy 段 dt=12，仅覆盖前 12h，导致 synergy 贡献在日产出计算中折半。
> 纯技能加成 = 直接效率(65%) + synergy折半(13.5%) = 78.5%，与代码输出 80.5% 有细微误差待定位。

## 结论

1. B1（宿舍感知信息）和 B4（魔物料理）的代码生成器已补充实现，152 个测试全绿
2. 实现后的纯技能加成从 75% 提升到 ~80.5%，缩小了 5.5 个百分点
3. 与期望值 140% 仍有 59.5 个百分点的重大偏离
4. 主要缺口来源于 synergy T=12h 与 production 24h 积分的不匹配，以及可能的其他未建模 buff
