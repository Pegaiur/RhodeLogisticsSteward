# 求解器架构：制造站驱动中枢选择

**日期**: 2026-05-27

---

## 改动摘要

去除 `FIXED_CONTROL` 固定中枢方案，改为**制造站 combo 驱动中枢选择**：

- `compute_optimal_support(combo)` — 根据制造站 3 人组返回支撑干员集
- `_evaluate_with_support(combo, ...)` — 评估 combo 含支撑的完整评分
- `_greedy_allocate_with_support(...)` — 贪心分配含支撑干员冲突检查
- `solve_mvp` 中枢不再固定，由所有选中 combo 的支撑干员并集填充

## 支撑干员集

| combo 类型 | 支撑干员 | 设施分配 |
|-----------|---------|---------|
| 含迷迭香 | 令+夕+黑键+爱丽丝+车尔尼+森西 | Control×2, Trade×1, Dorm×3 |
| 含骑士 | 薇薇安娜 | Control×1 |
| 含红松骑士团 | 焰尾 | Control×1 |
| 纯效率 | 无 | — |

## 贪心分配

```
1. 穷举所有 combo → 评估含支撑的完整评分 → 排序
2. 依序贪心选取：
   - 冲突检查：combo 干员 + 支撑干员 均已分配 → 跳过
   - 选中后：锁定 combo 干员 + 支撑干员
3. 中枢由累计支撑干员填充
4. 剩余设施贪心（不变）
```

## 测试

5 个新测试 + 160 全绿。组合空间不变（~1,500/产物），支撑干员查找 O(1)。
